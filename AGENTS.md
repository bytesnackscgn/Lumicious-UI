Short description:
Lumicious is a Vue 3 component library for building beautiful and functional user interfaces with ease.
It is a kind of glassy/glasmorphism ui component library.

Packagemanager: pnpm
Use `nvm use` for setting up node

Style: Tailwindcss

Main Framework: Vue 3

Component Structure:
- {ComponentName}
  - {ComponentName}.vue
  - {ComponentName}.stories.ts
  - styles.ts
  - types.ts
  - constants.ts
  - index.ts
  - utils.ts
